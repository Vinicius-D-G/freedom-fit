# Freedom Fit - Sistema de Prevenção à Evasão

Sistema inteligente de prevenção à evasão de alunos em academias usando IA preditiva.

## Tecnologias Utilizadas
- HTML5, CSS3, JavaScript
- Firebase (Firestore)
- Chart.js para visualização de dados
- VLibras para acessibilidade

## Funcionalidades
- Análise preditiva de evasão
- Identificação de alunos em risco
- Dashboard com estatísticas
- Recomendações personalizadas

## Como Executar
1. Clone este repositório
2. Abra o arquivo `index.html` no navegador
